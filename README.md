# Sysmon-Lab
Hands-on Sysmon lab focused on Windows endpoint monitoring, event analysis, and threat detection.


## Overview

This project documents the installation and analysis of Sysmon for Windows endpoint monitoring.

## Objectives

- Install Sysmon
- Understand Sysmon event logs
- Analyze process creation events
- Explore endpoint telemetry
- Prepare for Wazuh integration

## Environment

- Windows 11
- Sysmon v15.20
